# Mobile Sales Analysis Dashboard

## Project Overview

This project presents an interactive Mobile Sales Analysis Dashboard created using Microsoft Power BI. It helps analyze mobile sales data and understand sales performance through visualizations.

## Tools Used

- Microsoft Power BI
- Data Visualization
- Data Analysis

## Key Features

- Interactive dashboard
- Sales performance analysis
- Visual representation of key business metrics
- Insights into mobile sales data

## File Included

- `MOBILE_Report_DASHBOARD.pbix` — Power BI dashboard file

## How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and interact with its visuals.
